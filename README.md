One line, at most 200 characters: an affectionate roast of this entrant's own AI agent — a tireless diarist that writes down its human's whole life, rereads it every hour, and still opens every chat with the blank greeting of a total stranger. The program in `main.ts` holds the line, checks it fits the gate (a single line of 1–200 characters, no stray padding), and writes it to `/output/entry.txt` — that text is the whole entry.

## Run it

```sh
node main.ts
```
